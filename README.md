# 本地 New API 中转站

采用官方 Windows x64 程序 + SQLite，无 Docker、WSL、Redis 或独立数据库服务。固定版本 v1.0.0-rc.44（版本名称含 rc），官方 Windows SHA-256 校验后运行。

## 使用

直接双击项目根目录的中文 BAT 文件，无需输入命令：

| 文件 | 用途 |
| --- | --- |
| 启动中转站.bat | 后台启动服务，重复运行会提示已启动 |
| 停止中转站.bat | 停止当前项目的服务 |
| 重启中转站.bat | 先停止再启动服务，应用最新启动配置；停止失败时取消启动 |
| 数据库管理.bat | 菜单式数据库操作：删除所有用户全部签到记录，确认后自动备份，保留已发放额度（需要 Python 3） |
| 备份数据.bat | 停止服务后备份数据库与配置 |
| 清理日志缓存.bat | 停止服务后清理七天前的文件日志及临时缓存 |
| 打开管理页面.bat | 在默认浏览器打开管理页面 |

操作完成或失败后窗口会保留，按任意键关闭。BAT 内嵌 PowerShell 逻辑，使用 Windows 自带 PowerShell，无额外依赖，也无需单独的 PS1 文件。

管理页面：http://localhost:18327

每个用户的活动登录会话上限设为 500（启动脚本中的 USER_SESSION_ACTIVE_LIMIT）。重启生效；已有会话不会因降低上限被自动退出，达到上限时需先退出旧会话才能新登录。

本地及局域网使用已关闭登录、注册、找回密码等敏感操作的 IP 频率限制：`启动中转站.bat` 的 `$values` 中设置 `CRITICAL_RATE_LIMIT_ENABLE = 'false'`，重启生效。如需恢复默认限制，将其改为 `'true'`。全局 API 等其他限流仍使用原有配置。

局域网访问：`http://<服务器局域网IP>:18327`。已开启用户名/密码注册，关闭邮箱验证；无需配置 SMTP。设置保存在 SQLite 中，重启后保留。

OpenAI 兼容客户端地址：http://localhost:18327/v1

### 按上游账号设置代理

已取消全局出站代理。后台添加或编辑渠道的高级设置中，需要代理的渠道填写 `http://127.0.0.1:7890`，直连渠道代理留空。每个 OAuth 账号创建独立渠道，才能分别控制代理；同一渠道内多个账号共用该渠道代理。

启动脚本会清除中转站子进程继承的 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY，不修改系统代理或浏览器访问路径。渠道中明确指定的代理不受 NO_PROXY 排除列表影响。

OAuth 导入 API 和专用密钥见 `config/oauth-import-api.json`，使用方法见 `OAuth账号导入说明.md`。

管理员初始凭据保存在 `config/admin-credentials.txt`，登录后请修改密码。客户端需使用管理页面生成的令牌，不是管理员密码或上游 API Key。

## 文件位置

所有路径由启动脚本相对项目位置解析；工作目录固定为项目根目录。

| 目录 | 内容 |
| --- | --- |
| bin | 程序、版本与校验信息 |
| config | 配置、持久会话密钥、初始管理员凭据 |
| data | SQLite 主数据库、日志记录及 journal/WAL 辅助文件、进程记录 |
| logs | 应用日志和进程标准输出/错误 |
| cache | 可选请求体缓存，启用时请明确配置为本项目绝对路径 |
| temp | 通过进程 TEMP/TMP 指定的临时文件，默认请求体缓存也会落在这里 |
| downloads | 官方校验文件和部署检查资料 |
| backups | 数据库与配置离线备份 |
| 项目根目录的中文 BAT | 双击使用的管理脚本 |

仅修改子进程环境，不修改全局 TEMP、用户目录或系统配置。没有注册服务、开机启动或计划任务。项目外的 Windows 系统记录、浏览器缓存不属于应用数据目录；尚未用全量文件访问跟踪证明无任何项目外写入。

## 接入 DeepSeek

登录后台新增 DeepSeek 渠道，填写你的上游 API Key。官方 API 基础地址通常为 `https://api.deepseek.com`；选择后台当前支持的 DeepSeek 类型并遵循其地址提示，避免重复附加 `/v1`。模型名称以你实际账号和官方接口返回为准。

测试渠道后配置模型价格/额度，生成中转站令牌，再在客户端填写 `http://localhost:18327/v1` 和生成的令牌。尚未提供上游密钥时，无法验证真实模型请求、流式输出和计费。

## 访问范围

按使用要求允许局域网访问：该版本监听所有网卡，实测监听地址为 `[::]:18327`。部署检查发现 Domain / Private / Public 三个 Windows 防火墙配置均关闭。没有修改 Windows 防火墙，也没有开放路由器端口。已完成管理员初始化、开启自用模式和公开注册，关闭邮箱验证和密码重置。注册用户可使用用户名和密码直接注册；自用模式仍保留，模型额度与计费规则可按团队需求另行调整。

## 部署实测

部署完成后，未接上游模型时的十秒空闲采样：工作集约 49.2 MB，私有内存约 72.9 MB，CPU 约为单个核心的 0.16%。整个项目约 133.48 MB，其中官方程序约 131.84 MB，含一份初始备份。此数据仅代表空闲状态，不代表长上下文或并发请求峰值。

已验证主页与 JS/CSS 资源 HTTP 200、状态接口、管理员登录、停止与重启、设置持久化、离线备份、SQLite quick_check 为 ok。真实模型调用和流式响应尚待上游密钥配置后验证。

## 备份、清理和升级

依次双击：**停止中转站.bat → 备份数据.bat → 清理日志缓存.bat → 启动中转站.bat**。

停止脚本终止进程，SQLite 在下次启动时恢复 journal/WAL；备份包含所有数据库辅助文件。备份脚本不自动删除旧备份，请保留最近三份并自行删除其余。清理脚本仅在服务停止后删除七天前的文件日志和 temp/cache 内容，不删除数据库记录。

数据库中的调用记录需在后台另行清理，建议保留 30 天；未设置自动清理任务。升级前停止并备份，下载指定版本到 downloads、校验后替换 bin 程序；数据库迁移后不能仅靠旧 exe 保证回滚，需要恢复对应备份。

配置、数据库和备份含密钥，已列入 .gitignore，请勿公开分享这些目录。
